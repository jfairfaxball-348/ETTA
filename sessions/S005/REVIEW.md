# S005 review

The model receives only canonical nearby-object observations reconstructed from validated body/lamp fields. It cannot choose endpoints, write positions, invent targets or bypass world interaction permissions. The browser rechecks live state and consumes approval once. Stop/reset/manual changes/focus loss/expiry invalidate late responses.

Secrets remain server-side; site access token is memory-only in the password field and HTTP Authorization header. Auth/origin/content/body validation precedes the shared budget and Google call. Redis reservation is atomic, uses its own clock and fails closed; no in-memory fallback, retry loop or production fixture switch. Provider/error bodies are not exposed or logged.

Limits: this is a single-tab client-reported world, not server-attested simulation. Only WAIT and lamp toggle exist; no navigation, persistent memory or autonomous loop. Google and hosted Redis remain unverified. A successful fixture is not a model decision. Review/build/browser/hosted observations are recorded in VALIDATION rather than presumed.
